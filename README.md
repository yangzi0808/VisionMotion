# VisionMotion

**基于计算机视觉的低成本非接触式位移与振动监测系统**

用普通的手机或电脑摄像头拍摄简单机械目标的运动视频，通过计算机视觉方法逐帧提取目标中心位置，
从而得到位移-时间曲线、振动周期与频率，并给出简单的状态判断结果。

本项目是本科生独立完成的小型光电与计算机视觉项目。重点不是算法有多"高级"，
而是整条测量链路能跑通、每一步都能解释清楚、出错时能自己调试。
因此代码与文档都优先保证**简单、清晰、可复现**，不引入没有明确必要的技术。

## 计划使用的工具

| 用途 | 工具 |
| --- | --- |
| 读取视频、图像预处理、阈值分割、轮廓检测 | OpenCV |
| 数组运算、质心与基础统计 | NumPy |
| 位移-时间曲线与结果绘图 | Matplotlib |

这三个库记录在 `requirements.txt` 中，已安装在项目专用虚拟环境 `.venv` 中并验证通过（M1 完成）。
如需重建环境，请使用虚拟环境内的 Python：

```bash
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 目录结构

