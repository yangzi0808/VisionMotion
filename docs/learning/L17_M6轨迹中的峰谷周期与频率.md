## 12. 【概念解释】频率：每秒完成多少个完整周期

- 定义：**f = 1 / T**；
- 代入冻结值：T = 0.542593 s → f = 1 / 0.542593 ≈ **1.843003 Hz**（与第 114 行一致）；
- Hz = 1/s：1 Hz 表示"每秒完成 1 次完整周期"；1.843003 Hz 表示每秒约 1.84 个完整周期；
- 物理直觉：一个完整周期耗时约 0.54 s，比 0.5 s 略多一点，所以每秒不到 2 个周期——与 M6 视频里画面中 ~1.8 Hz 的往复节奏相符；
- 图 B（`make_figure_b()` 第 388 行起）把 1.843003 Hz（实验）、1.862134625 Hz（理论）、1.875 Hz（FFT 封板对照）放在同一根频率数轴上比较；**FFT 的数学内容留到下一课**，本课只登记这三个封板数字的出处（第 121–124 行）。
